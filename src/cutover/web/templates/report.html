Resumo executivo

Resumo executivo: AI-IS sem migração de plataforma

Foi solicitada uma avaliação técnica e econômica para determinar se a IA pode reduzir o esforço manual do assessment AS-IS de dados sem elevar o risco, respeitando uma restrição crítica: nenhuma linha de dados é enviada ao modelo e nenhuma sugestão é aplicada sem aprovação humana. Foram executadas {{ t.runs }} chamadas reais a um modelo de linguagem sobre {{ llm.method.datasets }} datasets, com {{ llm.method.repetitions }} repetições cada.

A investigação indica GO CONDICIONAL para um piloto. A viabilidade técnica está demonstrada ({{ t.successful }} de {{ t.runs }} chamadas concluídas, {{ t.runs_with_all_checks_passed }} com todas as verificações aprovadas) e o custo do modelo é desprezível (US$ {{ t.cost_usd_mean | br_dec(6) }} por dataset). Porém o ganho econômico sobre um time de dados e engenharia ainda não está provado: nenhuma hora humana foi cronometrada.

Principais achados técnicos

  • Viável e barato: custo total de US$ {{ t.cost_usd_total | br_dec(4) }} para {{ t.runs }} chamadas; {{ t.input_tokens_total | br_int }} tokens de entrada e {{ t.output_tokens_total | br_int }} de saída, medidos pelo provedor.
  • Velocidade com cauda longa: mediana de {{ (t.latency_ms_median / 1000) | br_dec(1) }} s, p95 de {{ (t.latency_ms_p95 / 1000) | br_dec(1) }} s e máximo de {{ (t.latency_ms_max / 1000) | br_dec(1) }} s. O pior caso custou {{ cost_tail | br_dec(1) }}× a média.
  • Não determinístico: {{ t.columns_total - t.columns_stable_across_reps }} de {{ t.columns_total }} colunas mudaram de destino ou tipo entre repetições. Toda sugestão exige aprovação humana.
  • Governança de custo: cada chamada passa por score, nível, teto de tokens, orçamento e auditoria em livro-razão (Tollgate).
  • Perfilamento determinístico: {{ profile.totals.rows | br_int if profile else '—' }} linhas perfiladas, hash SHA-256 conferido em {{ profile.totals.sha256_confirmed_on_page if profile else '—' }} arquivos e {{ profile.detection.defects_detected if profile else '—' }} de {{ profile.detection.defects_injected if profile else '—' }} defeitos injetados detectados.

Decisão pedida ao patrocinador

Pede-se a aprovação de duas ações imediatas:

  1. Autorizar o piloto AI-IS (estimativa de {{ wbs_total | br_dec(0) }} horas, cerca de {{ wbs_weeks | br_dec(1) }} semanas para uma pessoa a 25 h/semana): rodar o AI-IS em 5 datasets reais e cronometrar o assessment manual nos mesmos datasets.
  2. Comprometer os pré-requisitos: liberar uma amostra de datasets sob acordo de confidencialidade, alocar 1 a 2 analistas para o baseline manual e disponibilizar um ambiente com HTTPS.

Escopo e qualificação

Relatório de qualificação: o que o AI-IS cobre e o que deixa de fora

AI-IS é o assessment do estado atual (AS-IS) dos dados feito com IA e entregue sem migrar de plataforma. O valor está em levantar, documentar e sugerir mapeamentos com evidência, sem o custo e o risco de uma migração. Migração, validação e reconciliação ficam fora do escopo.

Decisão

Recomendação e decisão

Três caminhos, com critérios para decidir

1. Opções

OpçãoQuando faz sentidoO que falta
Piloto AI-IS (recomendado)Há um cliente com dados reais e disposição de medir o baseline manual em paralelo.Acordo de dados, ambiente com HTTPS, cronometragem de 5 datasets à mão.
Ampliar a cobertura antesO risco for a qualidade em outras origens (Oracle, Snowflake, SAP).Conectores de origem e mais fixtures.
Não prosseguirO ganho de horas não justificar a revisão humana.Rodar o cálculo da seção 05 com os números do seu time.

2. Critérios de sucesso propostos para o piloto

A calibrar com o cliente:

  1. Baseline medido em 5 datasets, com o tempo humano cronometrado.
  2. Taxa de sugestões aceitas sem edição pelos revisores, definida antes do início.
  3. Custo de IA por dataset abaixo do custo de 1 hora do time.
  4. Tempo de revisão por dataset abaixo do baseline manual.
  5. Zero linhas de dados enviadas ao modelo.

3. Decisão pedida

Autorizar o piloto AI-IS e comprometer os pré-requisitos descritos no resumo executivo. A decisão de investir continua sendo do patrocinador; este relatório separa o que foi medido do que foi assumido para que ela seja tomada com esse critério.
